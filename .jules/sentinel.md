## 2024-06-15 - Path Traversal Vulnerability in Module Resolution
**Vulnerability:** The TypeScript dependency extractor manually normalized paths when canonicalization failed using `std::path::Component::ParentDir` to blindly pop components from the resolved path. This could allow path traversal attacks where malicious relative imports (e.g., `../../../etc/passwd`) escape the intended root directory.
**Learning:** Manual path normalization is error-prone. Naively popping components for `..` segments fails to account for scenarios where `..` segments exceed the path depth, or when the base path is absolute (`RootDir` or `Prefix`).
**Prevention:** When manually resolving paths with `std::path::Component`, explicitly block `Component::ParentDir` from popping `Component::RootDir` or `Component::Prefix`. If the components list is empty or its last element is `Component::ParentDir`, push the new `Component::ParentDir` instead of popping to correctly preserve relative paths.
