## 2024-05-18 - Fix Path Traversal in Manual Path Normalization
**Vulnerability:** A path traversal vulnerability existed in `crates/flow/src/incremental/extractors/typescript.rs` during manual path normalization. The code handled `Component::ParentDir` (`..`) simply by calling `components.pop()`.
**Learning:** This simplistic handling of `..` allowed popping past the root directory or base directory. When normalizing relative paths with multiple `..` components that go above the base directory (e.g., `../../a`), `components.pop()` fails to preserve the necessary `..` components if the components list becomes empty, losing the relative navigation and effectively escaping intended directory bounds or creating incorrect paths.
**Prevention:** When manually normalizing paths using `std::path::Component`, never blindly pop on `Component::ParentDir`. Explicitly prevent popping `Component::RootDir` or `Component::Prefix`. If the components list is empty or its last element is already a `Component::ParentDir`, the new `Component::ParentDir` must be pushed onto the list rather than ignored, to properly preserve relative path structures like `../../`.
