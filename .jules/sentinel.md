## 2024-06-13 - Path Traversal in Manual Path Normalization
**Vulnerability:** A path traversal vulnerability in `crates/flow/src/incremental/extractors/typescript.rs` where manual resolution of unresolved `../` paths with `std::path::Component::ParentDir` could incorrectly pop `RootDir` or `Prefix` components, or wrongly collapse `../..` components if `components.pop()` is called blindly.
**Learning:** This occurred because `canonicalize()` fails if the file doesn't exist, leading to a naive fallback that just iterates `components()` and calls `pop()` unconditionally for every `ParentDir`. This blind popping is insecure because it doesn't consider what it's popping.
**Prevention:** When manually resolving paths with `std::path::Component`, block `Component::ParentDir` from popping `Component::RootDir` or `Component::Prefix`. If the components list is empty or the last component is `ParentDir`, we must push the new `ParentDir` rather than popping it to correctly preserve paths like `../../a`.
